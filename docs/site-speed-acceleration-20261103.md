# 寰宇医疗：缓存结果与付费加速方案

记录日期：2026-11-03。建议顺序：**先用现有缓存保证重复访问，再补中国内地节点，最后按实测购买动态加速。当前无扩容 ECS 的依据。**

## 1. 已上线：重复访问优先读本地缓存

| 对象 | 生效策略 | 更新方式 |
| --- | --- | --- |
| 公共图片、字体、JS/CSS | 内容哈希地址，一年期浏览器/CDN缓存 | 文件变化才改地址；未变文件跨版本继续复用 |
| 匿名公共页面框架 | 首次完成加载后本地缓存页面壳；不等待HTML回源即可开始渲染 | 后台检查 Worker，新壳安装后用于下一次导航；显式更新可绕过旧壳 |
| 首页与牙科匿名HTML | 两域名60秒CDN缓存 | 发布时刷新；源站不缓存身份请求，CDN按Cookie/Authorization隔离 |
| 版本文件与Worker | `no-store` | 保留轻量检查，避免一直读旧页面 |
| 病例、报告、上传资料、后台、专家工作台 | 不进入上述公共页面缓存 | 继续走现有鉴权与业务请求 |

本地和线上均验证：首页、牙科重复访问，以及关闭浏览器后重开，已加载的静态资源传输为 **0**；模拟新发布后，未变资源继续0下载。首次未加载的弹窗/下方资源仍需下载；浏览器主动回收缓存、手动清理、强制刷新也可能重新请求。这不等同于在磁盘永久保存所有页面。

已完成源站Gzip/缓存配置、两个CDN域名遵循源站策略、HTTP/2、证书更新及77项关键资源官方预热。现有CDN本身仍按其账单计费，本轮没有新增付费产品或扩容。

## 2. 首开瓶颈

现有CDN覆盖为 **全球（不含中国内地）**。阿里云说明，此范围下大陆访客会被调度到香港、日本、新加坡等境外节点，仍需经过跨境公网。

公网实测出现TLS连接重置；当前网络首页一个首开样本约7秒，牙科成功复测LCP约3.7秒。源站回环响应约0.1秒，当前没有服务器容量瓶颈。静态资源即使命中CDN，建连和链路波动也会拖慢首开。因此，本轮缓存已经解决“反复下载”，剩余主要延迟不能靠再压缩几KB图片或扩容解决。

## 3. 付费选择与实施顺序

| 顺序 | 方案 | 具体落地 | 购买/准备内容 |
| --- | --- | --- | --- |
| **首选** | 现有CDN改为全球覆盖，包含大陆 | 两域名接入大陆及海外就近节点；保留哈希缓存与发布预热；按主要地区复测 | **域名ICP备案**；按地区购买匹配的CDN流量/HTTPS请求包，或先按量试点 |
| 按首开实测选用 | HTTP/3 / QUIC | 在弱网和高延迟地区对比HTTP/2，验证UDP不可用时回退 | QUIC请求单独计费；没有明显收益则不启用 |
| **动态链路仍慢时** | DCDN/ESA或GA | 对API、登录、上传、支付会话等动态入口做区域试点；先选一条路线验证 | DCDN/ESA套餐或动态请求/流量；GA实例、容量与跨地域流量等，按购买页计费 |
| 流量/发布压力增长时 | 公共静态资源OSS＋CDN | 公共图片、字体、JS/CSS迁至OSS，由CDN回源；病例资料继续鉴权 | OSS存储、请求及回源流量费用；这项不能单独解决动态API慢 |

**大陆节点是关键前提。** 阿里云要求，CDN加速区域选“全球”或“仅中国内地”时，域名必须备案。当前未核实域名备案情况；若尚未备案，需要先准备对应主体和备案接入条件，由云厂商确认后办理。仅购买更大海外流量包、GA或升级新加坡ECS，不能替代这一前提或保证大陆秒开。

证书方面，目前使用的个人测试证书有效期至2027-01-31（北京时间）。正式运营应换成允许生产用途且能持续续期的证书；可选择适用的自动续期免费证书或购买正式证书，**不必为了加速单独购买昂贵证书**。

## 4. 费用怎么估算

优先按量试点7–14天，再根据地区流量购买资源包。CDN资源包通常降低费用，不会自动提升节点等级或修复慢链路；费用预警也不是强制消费上限。

阿里云基础流量计费文档在0–10TB档列出的示例单价：中国内地0.24元/GB，北美/欧洲0.46元/GB，亚太约0.58–0.78元/GB，中东/非洲/南美1.31元/GB。仅以 **100GB下行流量** 举例，基础流量约24–131元；另计HTTPS/QUIC请求、源站出口等。该数字不包含GA、ESA或OSS，不是账号正式报价。

GA包含持续实例费用等，不能用CDN每GB价格估算；跨境带宽/流量还需按地区单独确认。当前缺少真实月流量与地区占比，不建议直接买长期套餐。正式预算采用：**各地区实际下行GB×该区单价＋请求费用＋源站/可选产品费用**，以控制台报价及首期账单校准。

## 5. 验收与上线

- 覆盖中国大陆电信/联通/移动，以及香港、新加坡、马来西亚、美国、英国/德国等首批代表点；国家清单再按实际客户分布扩展。
- 各地区分别测试冷浏览器、CDN热缓存、重复访问；发布前后均测，保留失败和重置样本。先验证节点覆盖，连续7天看P75与错误率，不采用最快单次。
- 首屏目标：正常目标网络 **LCP P75≤2.5秒**，争取1秒级可见；HTML TTFB P75≤800ms，INP≤200ms、CLS≤0.1。用户已访问的静态资源常规再次打开传输为0，更新后能自动取得新文件。
- 病例、报告、上传和专属响应始终不进入公共缓存；支付与API正确性不能用扩大缓存换速度。每次配置保留备份，出现错误率上升即恢复配置并清理受影响入口。

“包括大陆的全球主要国家秒开”作为验收目标推进，须由地区试点证明。**推荐先做全球CDN覆盖及备案，动态API不达标再购买DCDN/ESA或GA。** 当前已完成无需新增产品的缓存优化，尚未购买上述方案。
