# M05：WhatsApp 自有埋点与后端拉取

用户确认：不接外部分析/广告工具，采用自有埋点记录、后端拉取统计。覆盖 M02 的中/英/印尼/马来/葡语及现有公开病种。此次为行为接入，没有修改患者页面构图、文字样式、Figma源数据、医院后台或医疗报告生成。

## 代码接入

- `src/composables/useWhatsAppContact.ts` 的共享患者联系上下文安装一次 `useContactAnalytics`；通过已有 `data-contact-entry` 识别所有悬浮/共享页脚/源稿页脚入口，不给递归源节点重复安装监听器。
- 实际鼠标、键盘和中键激活才采集。浏览、悬停、代码合成点击、Facebook/邮件链接均不计为 WhatsApp 点击；不拦截链接、不等待统计返回。
- `src/utils/contactAnalytics.ts` 保存匿名浏览器/会话标识和最多20条待传事件；无可用存储时降级内存。网络失败、429和503按同一事件ID重试，24小时过期；服务端原子去重。
- 上报沿用 `VITE_API_BASE_URL`，写入 `/api/analytics/events`；使用 keepalive、5秒超时、`credentials:omit`、`referrerPolicy:no-referrer`。不传完整URL、预填正文、登录凭据或个人资料。
- M02 来源白名单增加 `utm_term`，用于投放链接显式提供的关键词。完整来源和病种名称仍保存在五语 i18n，不修改报告内容。

## 后端交付

- 独立 `contact_click_events` 表、索引、小连接池；不关联或改写患者数据。
- `GET /api/expert/analytics/contacts`：既有管理员登录权限，支持日期/时区、语言、病种、页面、入口、广告来源/系列/关键词筛选及组合分组分页；返回点击次数、匿名浏览器去重数、会话数。没有转化率或已接通对话量。
- 服务端 `contacts:stats` 提供 JSON/CSV 拉取；普通专家及匿名请求不能读取统计。
- 接口、统计口径、使用命令、发布顺序与限制：`../../../Studio-huanyu-Server/docs/contact-analytics.md`。
