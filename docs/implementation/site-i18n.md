## 语言包

- `src/i18n/locales/`：现有按业务命名的键，包含 M02 五语联络与病种。
- `src/i18n/site-copy/zh.json`：从实际源代码、公开医生资料及 Figma 源文案提取的文案索引。源文本变动产生新键，不沿用旧译文。
- `src/i18n/site-copy/{en,id,ms,pt}.json`：离线生成、入 Git 的静态译文；按用户所选语言懒加载。
- `templates.json`：带动态参数的静态 UI 句式。不能添加只有参数、没有固定词语的全匹配句式。
- `useSiteCopy()` 的 `tx()` 处理静态公开文案，`tf()` 插入命名参数。筛选值/路由/医生 ID/表单提交值保留原值，仅翻译展示标签。完整句子使用占位符，不拼接“共”“位医生”等语言片段。
- 语言包加载成功后统一切换界面、`html[lang]`、存储与 URL。加载失败保持原语言并提示；防止连续切换时较慢的旧请求覆盖新语言。

## 每次修改文案

1. 按 Figma 门禁核对当前页面来源，修改中文源文案或公开资料。
2. `pnpm i18n:extract`，检查新增源文案与 `artifacts/i18n-20261104/locations.json`。
3. `pnpm i18n:translate`，只发送公开静态文案，断点保存成功批次。默认使用后端 `.env` 中的 GPT 配置；可通过 `HUANYU_TRANSLATION_API_KEY/BASE_URL/MODEL` 指定专用翻译配置。密钥不能写入前端、提交 Git 或输出日志。
4. `pnpm audit:i18n:site` 必须零缺项、零无效项。会校验占位符、URL、邮箱及 HTML 标签保留。医学数字、否定词、资质及专有名词仍需要语义抽检。
5. `pnpm test:i18n:copy`、`pnpm test:i18n:layout`、类型检查、生产构建；再跑真实语言包的 `pnpm qa:i18n:site`、`pnpm qa:i18n:states` 并人工检查新截图。截图在 `artifacts/`，不入 Git。

`prebuild` 和 `build:app` 均执行全文完整度检查。漏翻、源文案未重新提取、占位符/数字/链接不一致都会阻止发布；不得绕过此检查发布。当前目录未补齐，因此发布构建按预期失败。单独运行 Vue 类型检查/Vite 编译成功不代表发布检查通过。

403/401 会停止后续批次，不循环重试。修复服务权限/配置后，重新运行即可，只补缺失或无效译文。不得用复制中文、占位英文、测试文案补齐语言包来通过审计。

## 排版

中文保留原 Figma 几何和基线。其他语言仅在文案发生翻译时重新计算固定坐标文本的宽高，按原 Auto Layout 方向和间距推开后续内容，保持原图片尺寸、镜像变换及卡片列间距；卡片同排等高。零高度收起状态不能因翻译自动打开。公共导航可换行，菜单在完整导航行下方；页脚、弹窗和按钮容器允许自然增高。

`src/i18n/sourceLayout.ts` 的几何测试覆盖镜像头像、百分比覆盖、卡片行列、收起状态和全宽背景。`qa:i18n:stress` 只在本机浏览器内注入加长文案，用于暴露排版风险，**不代表真实翻译验收通过**。移动端沿用已存在布局，不开展冻结中的移动端设计改版。

动态文案按固定语句优先级匹配，避免“查看…”吞掉详情后缀。包含任意括号/分隔符的公开字段使用命名参数；例如医生卡片通过 `labelValues` 分别传姓名与科室，不从拼好的字符串反推姓名。信任文章中已采用 CSS Grid 自然排版的内容沿用自然流，不能再叠加绝对坐标，否则会重复计算边距。关闭图标继续使用原始绝对定位。

截图复查补充修复：长按钮标签可以在按钮内换行；医生快捷筛选与科室下拉分两行并为结果区保留间隔；保险角标沿自然流排布，不能盖住标题。医院卡片保留同列宽和图片裁切窗口，小型绝对定位标签可在图片内横向增长，避免城市名、JCI 等被挤成竖排。Figma 品牌字标沿用图稿，不作为正文翻译。

自动化 QA 通过应用的 `setLocale()` 切换语言。除了 DOM 和 ARIA 文案，还读取 ECharts 实际渲染配置中的图例、坐标和雷达标签；仅修改测试字典而没有触发应用切换，会让 Canvas 继续显示旧文案，不能据此判定图表通过。
