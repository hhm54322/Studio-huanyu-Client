# M10：首次加载、五语资源与失败恢复

## 范围

患者站加载与恢复专项。保留现有 Figma 页面、图片、导航和业务流程；不修改医疗报告生成、后端、数据库或专家工作台。M06/M08 在研咨询功能不进入本次发布。

## 实现

- HTML 内置中、英、印尼、马来、葡语加载和重试提示，脚本或 CSS 请求失败时也有可操作的反馈。8 秒仍未就绪时显示网络提示。
- 全站外语正文按共享内容和 14 个页面范围拆包，由实际导入关系构建，包含页面可打开的详情和弹窗。首开只加载共享包和当前页包，后续页面按需下载并复用缓存；更新内容须同步通过五语目录审计。
- 当前路由资源与选定语言提前请求；目标路由、语言、必要样式就绪后再显示页面，避免先出现中文再切换外语。
- 一个版本在同一标签页最多自动刷新一次，且仅限未展示、未操作的桌面公共页。报告页、医院端、移动端、已展示或已有输入的页面均不会自动刷新。存储不可用时直接提供手动恢复。
- 站内跳转失败保留当前页面与输入；错误提示可关闭或由用户主动重试，成功跳转会清除错误提示。
- 继续使用内容哈希、一年 immutable 静态缓存和公共页面壳。发布保留旧哈希资源，入口、版本与 Worker 最后切换，避免旧访客引用失效资源。
